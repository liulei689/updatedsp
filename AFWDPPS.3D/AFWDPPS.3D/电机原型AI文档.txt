# 无刷力矩电机特性描述（AI友好格式）
# 本文件用于AI理解和建模仿真无刷力矩电机，内容为结构化的物理与控制特性描述，非参数堆砌。

## 1. 电机物理结构与工作原理
- 无刷力矩电机（BLDC Torque Motor）由定子（带三相绕组）、转子（永磁体）、轴承、壳体等组成。
- 定子绕组通入三相正弦电流，产生旋转磁场，驱动转子永磁体旋转。
- 通过矢量控制（FOC），可实现对转矩、速度、位置的高精度控制。

## 2. 输入输出因果关系（简化为单一控制电流输入）
- 主要输入：控制电流（I_ctrl），负载转矩（TL），环境温度（T_amb）。
- AI负责将I_ctrl转换为三相电流（ia, ib, ic）和电磁转矩（Te）。
- 主要输出：电磁转矩（Te），转速（ω），转子位置（θ），温升（ΔT），角度（Angle），陀螺仪角速度（Gyro_ω）。
- 因果关系：
  - I_ctrl → AI → (ia, ib, ic, Te)
  - 电磁转矩与负载转矩、转动惯量共同决定加速度：J*dω/dt = Te - TL - B*ω
  - 转速积分得位置：θ = ∫ω dt
  - 位置θ可直接转为角度Angle，Angle = θ * (180/π)，默认初始0度
  - 陀螺仪输出Gyro_ω = ω（与电机实时转速一致，可加噪声模拟）
  - 损耗（铜损、铁损、机械损）导致温升，影响电阻和性能

## 3. 动态响应与非线性
- 电机存在惯性，输入电流变化不会立刻引起转速变化。
- 存在电流、转矩、速度的饱和上限。
- 电磁特性近似线性，但在高电流/高磁通时会出现磁饱和，导致转矩-电流关系非线性。
- 摩擦、齿槽效应等引入微小周期性扰动。

## 4. 损耗与热效应
- 铜损：I?R，随电流平方增长，导致绕组温升。
- 铁损：与转速、磁通密度相关，随速度升高而增加。
- 机械损耗：轴承摩擦、风阻等，随转速增加。
- 温升影响电阻，进而影响铜损和控制精度。

## 5. 控制特性
- 采用FOC（矢量控制），可独立调节转矩和磁链。
- 电流环、速度环、位置环三级闭环，带宽依次降低。
- 过流、过速、过温等保护机制。
- 典型控制输入：期望转矩/速度/位置，控制器自动调节三相电流。

## 6. 典型工况与动态行为
- 空载启动：输入小电流，转速平滑上升。
- 负载突变：负载转矩突然增加，转速短暂下降，控制器提升电流补偿。
- 堵转：转子被卡住，电流迅速上升，保护机制动作。
- 过载：持续高负载，温升加快，可能触发过温保护。
- 反向制动：输入负电流，电机产生反向转矩，转速快速下降。

## 7. 适合AI建模的特性描述格式（单一控制电流输入，含角度与陀螺仪输出）
- 输入：控制电流（I_ctrl）、历史状态（ω, θ, Te, ΔT）、负载转矩、环境温度
- AI负责I_ctrl→(ia, ib, ic, Te)的映射
- 输出：电磁转矩（Te）、转速（ω）、位置（θ）、温升（ΔT）、角度（Angle）、陀螺仪角速度（Gyro_ω）
- 状态转移：
  - ω(t+1) = ω(t) + Δt/J * (Te(t) - TL(t) - B*ω(t))
  - θ(t+1) = θ(t) + Δt * ω(t)
  - Angle(t+1) = θ(t+1) * (180/π)，默认Angle(0)=0度
  - Gyro_ω(t+1) = ω(t+1)（可加噪声模拟陀螺仪输出）
  - ΔT(t+1) = ΔT(t) + Δt/Cth * (P_loss(t) - Q_cool(t))
- 非线性：
  - Te = f(I_ctrl, 磁饱和, 温度)
  - R = R0 * (1 + α * ΔT)
- 约束：
  - |I_ctrl| ≤ I_max
  - |Te| ≤ Te_max
  - |ω| ≤ ω_max
  - ΔT ≤ ΔT_max

## 8. 示例：输入输出因果链（单一控制电流输入，含角度与陀螺仪）
- 输入：I_ctrl=3A, TL=1Nm, T_amb=25°C
- 过程：
  - AI将I_ctrl=3A映射为ia, ib, ic, Te（如Te ≈ 2.4Nm）
  - J=0.00045kg·m?，B=0.001Nms
  - ω(t+1) = ω(t) + Δt/0.00045 * (2.4-1-0.001*ω(t))
  - θ(t+1) = θ(t) + Δt * ω(t)
  - Angle(t+1) = θ(t+1) * (180/π)，初始Angle(0)=0度
  - Gyro_ω(t+1) = ω(t+1)
  - 铜损=Te相关电流平方和*电阻
  - 温升随时间积累
- 输出：Te=2.4Nm, ω, θ, ΔT, Angle, Gyro_ω

## 9. 物理与控制特性总结
- 电机是一个多输入（电流、负载、温度）、多输出（转矩、速度、位置、温升）、强耦合、动态、非线性系统。
- 主要动力学由d-q轴模型描述，热、损耗、饱和等为重要影响因素。
- 控制系统通过调节电流，实现对输出的精确控制。
- 适合AI建模的输入输出、状态转移、约束、非线性关系已明确。
